# Industrial Sandbox HDBSCAN Training v0.1

## Purpose
This repository implements block `1B.2` of the industrial anomaly-detection program: `Correlation Engine Prep + Chaos Readiness Foundation`.

This block is not the full agentic layer and not the full chaos engine. Its mission is to prepare a serious, reproducible, and defensively-oriented temporal correlation lane that can later feed `1C`.

## Core Chain
```text
Synthetic Telemetry Generator mature
-> Scenario Engine stochastic
-> Common Telemetry Contract
-> Separate Feature Views
-> Multivariate Temporal Windows
-> HDBSCAN temporal
-> Defensive PropagationSignature
-> EligibilityValidator
-> ChaosTemplate placeholder
```

## Architectural Rules
- Do not break the existing `Isolation Forest` lane.
- Reuse the same synthetic world for both models.
- Keep `iforest_feature_view` and `hdbscan_temporal_feature_view` separate.
- Never train with metadata that will not exist in runtime inference.
- Keep `PropagationSignature` purely defensive.
- Keep `ChaosTemplate` separate and placeholder-only for now.
